## 已公开的调用规范

依据规则附件 3：

- 正式运行由主办方提供 `.env`，只含 `MODEL_NAME` 与 `ENDPOINT`。
- `ENDPOINT` 是完整 POST 地址，按 Chat Completions 兼容协议调用，无 API Key，不发送 Authorization。
- 规则中的 `replace_with_model_name` 与 `http://127.0.0.1:8000/v1/chat/completions` 明确是占位示例；127.0.0.1 指调用程序所在机器，不是可从互联网访问的赛方公网服务。
- 具体模型标识、完整地址、请求响应协议、调用/并发/超时/重试限制由赛前技术附件确认。
- 正式评测在主办方封闭网络环境运行，因此即使某个开发地址可访问，也不能推定为正式评测地址。

## 已补齐的接入工具

`tools/check_model_connection.py` 可在获得正式配置后做一次非医疗探测，不读取病例、不搜索接口、不重试、不尝试其他模型。调用示例：

```powershell
python tools/check_model_connection.py --check-only
python tools/check_model_connection.py
```

第一条只检查本地配置，不联网。第二条仅向 `.env` 中的完整地址发送 1 次简单 JSON 请求，最多 128 个输出 token；该请求应在赛方允许的开发/调试预算中使用。结果保存至 `artifacts/model_access_check.json`。连通性通过不等于确认模型版本或赛方授权，更不等于医学质量已验证。
