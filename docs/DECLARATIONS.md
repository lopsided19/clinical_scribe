# 参赛声明材料草稿

本文件是供队伍核对、补充并签署的材料草稿；尚未代表任何成员签字、接受协议或向赛方提交。

## 模型及版本声明

正式运行仅使用主办方提供且允许的模型服务。实际模型名称、版本与请求地址以赛方配置及最终运行日志为准。当前尚未取得正式服务信息，不能预填某个未经确认的 Qwen 版本。

本地 `LOCAL_TEST_MOCK_NOT_A_MODEL` 为工程回显接口，不是语言模型，不计为真实 Qwen 评测，不用于生成正式提交结果。项目开发过程由 AI 编程助手协助检索公开资料、编写代码与文档；最终人工审核、实际模型调用及材料真实性由参赛队伍核实。

## 检索资料来源及版本声明

当前正式算法不启用外部检索，不读取开发病例及参考答案。公开数据仅用于离线工程开发，来源、固定版本、哈希与许可见 `data/download_manifest.json` 和 `docs/DATA_SOURCES.md`。若后续启用检索，应先按赛方要求登记资料并获得允许，再更新此声明与算法固定版本。

CMB-Clin 的标题和问答答案不进入生成输入；MIMIC Demo 输入不使用出院诊断、死亡结局和截止点之后的检查结果。启发式处理及公开数据的局限已明确记录。

## 大模型使用说明

提示词与调用参数随算法源码提交。对正式病例使用同一固定版本，不人工改写医学正文、不逐例改变提示词、不择优挑选某次输出。所有提取、生成、修正和失败重试按同一调用预算记录。模型输出的事实忠实性和临床内容仍须医学评审评价，不以格式校验替代医学审查。

## 数据使用承诺文本

队伍应承诺：比赛病例仅在赛事允许的范围与期限内使用，不对外传播或挪作其他用途；正式运行只调用指定模型和允许的服务；不临时联网查找病例答案，不获取或缓存正式测试答案；不伪造运行记录或篡改日志；不将生成草稿作为真实诊疗依据；发现数据或系统问题向赛方反馈。

队伍名称、编号、成员、指导教师、承诺人及签署日期：由实际参赛人员在正式提交前填写并核对。此处不虚构身份和签名。
