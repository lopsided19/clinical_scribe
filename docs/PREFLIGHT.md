# 模型接入前的离线预检

```powershell
python tools/preflight.py --input data/prepared/cmb/dev.json
```

报告默认写入 `artifacts/preflight.json`。没有 `.env` 也可完成病例、源码、配置和预算检查；程序不发网络请求、不调用模型、不生成病历，也不自动创建 `.env`。

工具检查项目根目录的实际 `settings.json`，可通过 `--source-dir SOURCE_DIRECTORY` 检查另一份完整源码。它不会推测 `run_experiment.py --variant` 将生成的配置；该实验命令有自己的预设。要核对某次已冻结实验的预算，应把 `--source-dir` 指向那次运行目录。

报告包含输入文件与源码/配置哈希、病例编号、原文字数、可请求与无效病例数，以及以下预算：

- 每例实际可达到的请求上限，是配置调用上限与“阶段数 × 每阶段最多尝试次数”中较小者。基础阶段为生成，或提取加生成；启用修正时最多再增加一个阶段。修正触发与重试均有条件，因此不是预计请求量。
- 整批请求上限只计有效病例。无效病例在正式程序中保留失败位置，任务级超时可能使后面的有效病例也未能请求。
- 无重试、无修正且成功完成基础流程所需的调用数，供规划使用；不能当作任何运行的调用下限。
- 所有允许请求均达到单次超时的场景时长与配置总时限对比。该场景未包含本地处理开销，不是耗时预测或硬时限保证。
- 未接入实际模型分词器，token 估计为 null。原文字数不等于请求 token 数，模型上下文长度仍需正式接口验证。

报告不包含病例正文、提示词全文或完整接口 URL；配置文件里的 URL 查询参数也不写入报告。

状态含义：

| 状态 | 含义 | 退出码 |
|---|---|---|
| `blocked` | 输入顶层、源码文件或算法配置有错误，预检未完成 | 2 |
| `awaiting_model_configuration` | 离线检查完成，模型配置缺失、占位或格式无效 | 0 |
| `configuration_ready_unverified` | 离线检查完成，模型配置语法通过，网络和模型身份未验证 | 0 |

退出码 0 仅表示离线报告已完成，应同时查看状态、无效病例及警告。全部病例无效或输入为空时会明确提示；不会把它们算作可调用病例。MOCK 配置会提示仅供工程演示。

`--report PATH` 可另选报告位置，工具拒绝覆盖本次输入、模型配置和运行源码。报告哈希用于核对版本，不能认证赛方授权、接口真实模型版本或医学效果。
