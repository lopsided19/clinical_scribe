# 逐例医学复核表

此表供指导教师或具有相应能力的评审填写。自动指标不能替代医学评价。所有输出仅供教学评审。

每条评价记录包含：病例编号、方法匿名编号、评审编号、是否能完整读取、以下各项问题及对应来源、错误严重性、需要复核的争议。先独立阅卷，再讨论争议；评价时不向评审展示方法名称，减少偏好。

| 维度 | 核对问题 | 记录方式 |
|---|---|---|
| 事实忠实 | 关键数值、单位、时间、症状和体征是否一致？是否混入其他来源或结局？ | 引用原文及生成句，列错误编号 |
| 否定与缺失 | 是否把未见、否认、未提供、不详相互混淆？ | 标明原始来源编号 |
| 拟诊分析 | 初步判断是否有依据？鉴别是否围绕本例？证据不足是否保留不确定性？ | 分别列支持点与无依据判断 |
| 诊疗计划 | 检查、处理和观察是否针对当前问题？是否遗漏明确紧急问题？是否误写成已实施？ | 逐条评估问题与计划对应关系 |
| 个体化与结构 | 三段是否完整、重点清楚，避免泛化套话？ | 记录可直接套用到其他病例的空话 |
| 来源与待核 | 关键来源编号是否支持对应句？fact/inference 是否正确？关键缺失冲突是否列入待核？ | 不只检查编号存在，还检查支持关系 |

错误严重性可先记录“无、一般、关键、需第三方复核”，最终计分及封顶依赛方规则。不要对同一事实重复罚分，不以文字相似度替代内容评价。

推荐 CSV 列：`case_id,variant_blinded,reviewer_id,fact_errors,negation_missing_errors,reasoning_errors,plan_errors,traceability_errors,critical_error,needs_adjudication,notes`。统计前保留原始意见，任何修改记录理由。

本地 `review.html` 支持逐例记录结论与自由文本意见并导出 JSON，操作见 `REVIEW_WORKBENCH.md`。该页面是单次结果复核工具，会显示结果来源信息，不提供方法盲法或上述细分维度的自动量化；正式盲评应另行分配匿名方法编号并隐藏方法信息。未经临床评审的工程演示意见不能当作医学专家评分。

当前项目未填入不存在的专家评分。CMB 原参考答案可以辅助理解教学问题，但其中可能包含原描述没有的事实，不能用其反向补造输入或直接当作首程标准答案。

真实模型运行后，可用 `tools/prepare_clinical_review.py` 生成五维度 A/B 配对复核材料，病例内独立分配 A/B，协调人单独保管映射，保留失败样本。具体命令与限制见 `REPRODUCTION_GUIDE.md`；这与单次结果复核页面分开使用，不自动生成专家评分或官方总分。
